# 地理：第七章 认识大洲

- 科目：地理
- 年级：七年级
- 地区：深圳
- 模块顺序：知识模块07
- 所属目录：七年级下册

## 知识点汇总

### 亚洲及欧洲

1. 亚洲位置、范围、分区。
2. 亚洲地形复杂，中部高、四周低。
3. 亚洲河流多发源于中部高原山地，呈放射状流向周边海洋。
4. 亚洲气候复杂多样，季风气候显著，大陆性强。
5. 亚洲人口、文化、经济差异。
6. 欧洲位置、地形以平原为主，温带海洋性气候显著。
7. 欧洲人口、城市和经济发展特点。

### 非洲

1. 非洲地理位置：赤道穿过中部，大部分位于热带。
2. 地形以高原为主，被称为“高原大陆”。
3. 气候类型南北对称分布。
4. 尼罗河、刚果河、撒哈拉沙漠、东非大裂谷。
5. 矿产、生物和旅游资源。
6. 人口、粮食、环境与发展问题。

### 美洲

1. 北美洲和南美洲的位置、范围。
2. 美洲地形南北纵列分布，西部高大山系，中部平原，东部高原山地。
3. 北美洲温带大陆性气候广，南美洲热带范围大。
4. 亚马孙河、亚马孙平原、巴西高原、安第斯山脉。
5. 移民、文化融合和经济差异。

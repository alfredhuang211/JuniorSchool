# 生物学：第四单元 人体生理与健康（一）

- 科目：生物学
- 年级：七年级
- 地区：深圳
- 模块顺序：知识模块04
- 所属目录：七年级下册

## 知识点汇总

### 人的生殖和发育

1. 男、女生殖系统的主要器官及功能。
2. 受精、胚胎发育、分娩的基本过程。
3. 青春期身体变化：身高体重突增、性器官发育、第二性征出现。
4. 青春期心理健康与卫生保健。

### 人体的营养

1. 六类营养物质：糖类、脂肪、蛋白质、水、无机盐、维生素。
2. 糖类、脂肪、蛋白质的供能和构成作用。
3. 消化系统组成：消化道和消化腺。
4. 淀粉、蛋白质、脂肪的消化过程。
5. 小肠适于吸收的结构特点：长、绒毛多、毛细血管丰富、壁薄。
6. 合理营养、平衡膳食、食品安全。

### 人体的呼吸

1. 呼吸系统组成：呼吸道和肺。
2. 呼吸道对空气的处理：清洁、温暖、湿润。
3. 肺泡适于气体交换的结构特点。
4. 肺与外界气体交换，肺泡与血液气体交换。
5. 呼吸作用与人体能量供应的联系。
6. 空气质量、吸烟与呼吸健康。

### 人体内物质的运输

1. 血液组成：血浆、红细胞、白细胞、血小板。
2. 红细胞运输氧，白细胞防御保护，血小板止血凝血。
3. 血管类型：动脉、静脉、毛细血管。
4. 心脏四腔结构和瓣膜作用。
5. 体循环、肺循环的路径和意义。
6. 血型、输血安全的初步认识。

### 人体内废物的排出

1. 排泄与排遗的区别。
2. 泌尿系统组成：肾脏、输尿管、膀胱、尿道。
3. 肾单位结构：肾小球、肾小囊、肾小管。
4. 尿液形成：过滤作用和重吸收作用。
5. 排尿意义：排出废物、调节水和无机盐平衡。

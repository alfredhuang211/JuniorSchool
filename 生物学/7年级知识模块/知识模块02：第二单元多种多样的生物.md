# 生物学：第二单元 多种多样的生物

- 科目：生物学
- 年级：七年级
- 地区：深圳
- 模块顺序：知识模块02
- 所属目录：七年级上册

## 知识点汇总

### 植物的类群

1. 藻类、苔藓、蕨类植物的生活环境、结构特点和繁殖方式。
2. 种子植物分为裸子植物和被子植物。
3. 种子的基本结构：种皮、胚、胚乳等；胚包括胚芽、胚轴、胚根、子叶。
4. 比较不同植物类群从水生到陆生、从简单到复杂的演化趋势。

### 动物的类群

1. 无脊椎动物与脊椎动物的分类依据。
2. 常见无脊椎动物类群：腔肠动物、扁形动物、线形动物、环节动物、软体动物、节肢动物等。
3. 鱼、两栖动物、爬行动物、鸟、哺乳动物的主要特征。
4. 结构与功能适应：鱼鳃适于水中呼吸，鸟翼和气囊适应飞行，哺乳动物胎生哺乳提高后代成活率。

### 微生物

1. 微生物分布广泛，个体微小。
2. 细菌结构：细胞壁、细胞膜、细胞质、DNA 集中区域，部分有荚膜、鞭毛。
3. 细菌通过分裂生殖。
4. 真菌结构特点，酵母菌、霉菌、蘑菇等。
5. 病毒无细胞结构，由蛋白质外壳和内部遗传物质组成，必须寄生在活细胞中。
6. 微生物与人类生活：发酵食品、疾病、防腐、分解有机物。
7. 综合实践：利用细菌或真菌制作发酵食品。

### 生物分类的方法

1. 分类依据：形态结构、生理功能、亲缘关系等。
2. 分类单位：界、门、纲、目、科、属、种。
3. 种是最基本的分类单位。
4. 学会使用检索表和比较法对生物分类。

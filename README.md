# 深圳初中一年级学科知识点整理

整理日期：2026-08-31

本项目按深圳七年级常用教材版本与义务教育课程标准整理六门学科知识点：

- [数学](./数学/七年级知识点.md)
- [生物学](./生物学/七年级知识点.md)
- [物理](./物理/七年级知识点.md)
- [化学](./化学/七年级知识点.md)
- [历史](./历史/七年级知识点.md)
- [地理](./地理/七年级知识点.md)

各科目录下的 `7年级知识模块/` 子目录按教学顺序汇总知识点，每个文件对应一个章节、单元或主题模块。

## 适用说明

1. 课程依据采用教育部《义务教育课程方案和课程标准（2022年版）》，该方案自 2022 年秋季学期开始执行。
2. 深圳七年级常用教材版本参考公开教材版本信息：数学北师大版，生物学人教版，历史统编/人教版，地理湘教版。
3. 物理、化学在深圳初中属于中考录取计分科目，但七年级通常不开设独立物理、化学教材；两份文档整理的是七年级可提前建立的科学素养与跨学科衔接知识。
4. 不同学校可能因校本课程、进度安排和教材微调存在差异，应以学生所在学校发放教材和教学计划为准。
